# Benchmark Results

This directory is reserved for active benchmark outputs generated by the current benchmark layout and methodology.

## Intended Use

- keep fresh per-run and aggregate JSON outputs here
- treat this folder as a working area for iterative smoke, microbenchmark, and end-to-end runs
- avoid mixing new outputs with pre-cleanup historical artifacts

## Historical Results

Older benchmark outputs from before the repository consolidation were moved to:

- `benchmarks/results/historical/pre_rebaseline/`

Those files are archived for reference only. They are not the authoritative baseline for future algorithm work, and they should not be used for final comparisons or publication claims.

## Working Rule

Before a new benchmark campaign, clear or rotate only the active outputs that you intend to replace. Keep historical archives immutable once moved.
